Build recipes and upstream identity are included with source. Native installers will appear here when packaged and qualified for their operating systems.

A compiled source fork remains under qualification. Windows and macOS installers are not released.

Install on Linux
  1. Download and extract the Linux installer ZIP.
  2. Open a terminal in the extracted Flapart-Studio-Installer folder and run sh install.sh.
  3. Wait for the verified runtime download and installation. No administrator password is needed.
  4. Open Flapart Studio from your applications menu. Your existing Krita setup is kept separate.

The included README explains system requirements, upgrades and removal. Keep editable .kra files for native projects; export PNG to bring an image into the browser editor.

Install the Studio plugin
  1. Download and unzip the plugin archive.
  2. Read its README for the supported Krita version and installation steps.
  3. Copy the included pykrita and actions folders into Krita's resource folder, enable Flapart Studio in Python Plugin Manager, and restart Krita.
  4. Open Tools → Scripts → Flapart Studio.

Existing Krita settings and documents stay yours. The plugin's focus controls can be reversed. Save your editable work before exporting or closing.

What this edition supports

Layers, opacity and blend modes; pressure-sensitive strokes; drawing and shape tools; selections and movement; undo and redo; image import and export; local recovery; private cloud saves; explicit image sharing.

Browser projects are bounded to 4096 pixels per side, 32 layers and a total pixel budget. Cloud saves accept up to 16 MiB per project; larger projects can still be saved to your device. Pen pressure depends on your browser and device.

The browser editor is an original implementation informed by Krita research. It is not a port of Krita's full engine, and does not promise its animation, color-management, brush-engine or file-format coverage.

Questions and improvements belong in the Flapsoft community workshop. Source packages include tests and known limitations.
